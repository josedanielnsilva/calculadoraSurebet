# Calculadora Surebet

Calculadora web desenvolvida para identificar oportunidades de surebet e distribuir automaticamente os valores das apostas entre dois resultados.

## Demonstração

Acesse o projeto pelo GitHub Pages:

[Calculadora Surebet](https://josedanielnsilva.github.io/calculadoraSurebet/)

## Funcionalidades

- Verificação automática da existência de uma surebet;
- Cálculo do percentual estimado de lucro;
- Cálculo automático a partir do valor da Aposta 1;
- Cálculo automático a partir do valor da Aposta 2;
- Distribuição das apostas a partir do valor total;
- Recálculo automático ao alterar as odds;
- Exibição do lucro estimado para cada resultado;
- Validação dos valores informados;
- Layout responsivo para computadores e dispositivos móveis.

## Como usar

1. Informe as odds das duas casas de apostas;
2. Preencha um dos seguintes campos:
   - Aposta na Casa 1;
   - Aposta na Casa 2;
   - Valor total apostado;
3. Os demais valores serão calculados automaticamente;
4. Confira o percentual da surebet e o lucro estimado em cada resultado.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Executando localmente

Clone o repositório:

```bash
git clone https://github.com/josedanielnsilva/calculadoraSurebet.git
```

Entre na pasta do projeto:

```bash
cd calculadoraSurebet
```

Depois, abra o arquivo `index.html` no navegador.
