# Calculadora Surebet

Calculadora web para identificar oportunidades de surebet e distribuir automaticamente os valores das apostas entre dois resultados.

## Demonstração

Acesse o projeto pelo GitHub Pages:

[Calculadora Surebet](https://josedanielnsilva.github.io/calculadoraSurebet/)

## Funcionalidades

- Verificação automática da existência de uma surebet;
- Cálculo do percentual real de lucro;
- Distribuição automática a partir da Aposta 1;
- Distribuição automática a partir da Aposta 2;
- Distribuição das apostas a partir do valor total;
- Recálculo automático ao alterar as odds;
- Exibição do lucro estimado em cada resultado;
- Validação dos valores informados;
- Layout responsivo para computadores e dispositivos móveis.

## Como usar

1. Informe as odds das duas casas de apostas;
2. Preencha um dos seguintes valores:
   - Aposta na Casa 1;
   - Aposta na Casa 2;
   - Valor total apostado;
3. Os outros valores serão calculados automaticamente;
4. Confira o lucro estimado para cada resultado.
